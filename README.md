# treadcraft

Codex のスレッドを、RTS の部隊編成のように整理するローカルデスクトップアプリ。Tauri 2 / React / TypeScript / Rust / SQLite。

初期実装です。macOS でビルドと自動テストを確認。Windows / Linux の実機操作・配布インストーラーはまだ未検証です。

## 起動

Node.js 22.12 以降、Rust 1.93 以降、[各 OS の Tauri 開発前提条件](https://v2.tauri.app/start/prerequisites/)、Codex CLI 0.153.4 以降が必要です。API 互換性を実接続で確認したバージョンは 0.153.4 です。

```sh
npm ci
npm run tauri dev
```

macOS の GUI 起動などで CLI が見つからない場合:

```sh
TREADCRAFT_CODEX_BIN=/absolute/path/to/codex npm run tauri dev
```

Windows PowerShell では `$env:TREADCRAFT_CODEX_BIN = 'C:\path\to\codex.exe'` と設定してから起動してください。npm の `.cmd` ラッパーではなく実行可能な Codex バイナリを指定します。

`npm run dev` はブラウザー用フロントエンドだけを起動します。ブラウザーでは実データへ接続せず、デスクトップ版を開く案内を表示します。デモデータを実データとして表示するフォールバックはありません。

## 操作

- 未分類欄の左下の「＋」から新しいチャットを開始できます。既存のワークスペース、または「別のフォルダを指定…」で絶対パスを入力し、グループ（未分類も可）を選択します。作成後は右側のチャット欄が開きます。
- 送信前の会話はワークスペース・分類とともにこのアプリ内に保存されます。最初のメッセージ送信時に Codex の会話を作成し、以降も同じ会話を再開します。同期後もカードや分類は重複しません。

- 横並びのカンバン表示。左端は未分類（新しい順）、各グループは独立したレーンです。横スクロールで移動し、レーン内は縦スクロールできます。チャットはボードと別の右側ペインに表示します。
- 「グループ作成」から作成し、編集で改名、×で削除。
- カード左のドラッグハンドルでグループ間を移動。カードの上に落とすとその直前へ挿入。左へ戻すと分類解除。
- カード右の移動先メニューでも分類できます。
- カード内の「Zedで開く」で、そのスレッドの作業フォルダを Zed に開きます。チャットの選択や Codex の再開は行いません。macOS はインストール済みの Zed.app、Windows / Linux は PATH 上の `zed` コマンドを使用します。存在しないフォルダはエラー表示します。
- 未分類カードのクリックは選択のみで、チャット欄を開いたり切り替えたりしません。Enterでチャットを表示します。グループ内のカードはクリックで右端にチャット欄を表示します。直近100項目を時系列に表示し、「以前のメッセージを読み込む」で履歴を遡れます。
- 「送信」または ⌘ / Ctrl + Enter で同じ Codex スレッドに送信します。Enter は改行、日本語変換中は送信しません。既存の Codex ログイン・モデル設定を利用し、通常の利用枠を消費します。
- 応答は逐次表示し、「応答を停止」で中断できます。実行中もスレッド切替、ペインを閉じる、新規チャット作成、次の入力・設定変更ができます。応答はバックグラウンドで継続し、ヘッダーの実行中ボタンで戻れます。異なるチャットは同時送信できます。同じチャットへの重複送信は防止します。未送信の下書きはアプリ起動中だけスレッド別に保持します。
- 送信失敗時は下書きを残し、自動再送しません。送信済みの可能性があるため、履歴を再読み込みして確認してから再送信してください。他の Codex クライアントと同じスレッドに同時送信しないでください。
- グループはハンドルか左右ボタンで並べ替え、見出しで折りたたみ。ドラッグ中にボードの左右端へ近づけると横にスクロールします。
- 検索中はグループ間の移動のみ。並べ替えは検索を解除してから行います。
- グループ削除には確認があり、所属スレッドは未分類へ戻ります。会話そのものは削除しません。

## データと安全性

ヘッダーの「実行中」バッジは treadcraft からの送信開始〜終了（接続・停止処理を含む）に表示します。クリックすると検索を解除し、所属グループを展開して実行中カードへフォーカスを移します。チャットのストリームは再接続せず維持します。現在は同時に1件の送信に対応し、Zedなど別クライアントの実行状態はこのバッジには含みません。

未分類レーンは左に固定され、グループ側だけが横スクロールします。未分類のスレッド一覧は独立して縦スクロールできます。

文字入力中でなければ Shift＋1〜9 で左から対応するグループへフォーカスを移し、画面外のグループは見える位置へ横スクロールします。空・折りたたみ中のグループにも移動でき、チャット表示や分類は変更しません。入力欄・選択メニュー・ダイアログ・IME変換中は無効です。

グループ内も ↑ / ↓ で表示中のスレッドを選択し、Enter でチャットを開けます。グループ自体にフォーカスがある場合は ↓ で先頭、↑ で末尾へ移動します。矢印は選択のみで、チャットの切り替えや並べ替えは行いません。空・折りたたみ中のグループでは移動しません。

グループ内は未読を上に表示し、未読同士・既読同士ではスレッド更新時刻（updatedAt）が新しい順に並べます。更新時刻が未取得の場合は作成時刻を使います。グループ内の表示は手動順序ではなく、この自動ソートに従います。未分類は作成時刻の新しい順です。

グループまたはそのカードにフォーカスがあるとき、macOSは ⌘＋Enter、Windows / Linuxは Ctrl＋Enter で、そのグループ内の最新更新の未読チャットを開き、カードへフォーカスを移します。検索中は表示対象から選び、未読がなければ何もしません。折りたたみ中は展開し、同じチャットを開いていた場合も最新履歴を取得します。入力欄では反応せず、チャット入力欄の送信操作と実行中の切替禁止は維持します。

未分類カードにフォーカスがあるときは ↑ / ↓ でカード選択（フォーカス）を移動、Enter でチャットを開けます。macOS は ⌘＋1〜9、Windows / Linux は Ctrl＋1〜9 で、現在のグループ順の左から1〜9番目へ分類します。分類後は次の未分類カードへ、末尾なら前のカードへフォーカスを戻します。検索中は表示中の未分類カードが対象です。入力欄・移動先メニュー内ではショートカットを適用せず、存在しない番号は何もしません。

チャット入力欄の「モデル」「推論強度（グレード）」で、次回送信の設定を選べます。モデルと対応強度は Codex の `model/list` から取得し、モデル変更時はそのモデルの標準強度に戻します。「スレッドの設定を使用」は明示的な上書きを行いません。グレードは推論強度であり、契約プランや Fast / Priority の設定ではありません。

選択はスレッドごとにアプリを閉じるまで保持します。送信時の上書きは Codex の後続ターンにも反映されるため、「スレッドの設定を使用」に戻しても送信前の設定へ巻き戻す意味ではありません。送信中は変更できません。一覧の更新で選択が利用できなくなった場合は、送信前に選び直してください。モデルごとの利用可否・上限は Codex 側にも依存します。

未読マークは treadcraft 独自です。カードの青い点とレーンの「未読 N」は前回閲覧後に更新されたスレッド数（検索中は表示対象のみ）。導入後の初回同期は既読、それ以降の新規スレッドと更新を未読にします。最新履歴の取得に成功し、アプリが前面で表示されたときに既読を保存します。取得失敗やZed起動では消えません。開いたまま届いた更新は再読み込みで確認してください。

既読状態はローカルDBに永続化し、Zed等の既読状態とは同期しません。判定は Codex の `updatedAt`（秒単位）を利用するため、返信件数ではなく更新検知です。メタデータ更新も対象になり得て、同じ秒内の更新は区別できません。検出タイミングは通常の一覧同期と同じです。

- 分類は Codex セクションとは独立。通常の ChatGPT 会話、Zed 独自履歴、リモート端末との同期は対象外。
- `thread/list` でローカル CLI / VS Code / App Server のメタデータを取得。非アーカイブ・アーカイブ双方のページ取得完了後だけキャッシュを更新します。
- 名前未設定のスレッドは「無題のスレッド」。会話本文や JSONL を読んでタイトルを生成しません。
- `useStateDbOnly: true` を指定し、古い CLI に対するメタデータ走査・修復へのフォールバックはしません。
- 分類の変更は SQLite トランザクションと revision 検査で保護。同期によって分類は上書きされません。
- 一覧に一時的に現れなくなってもキャッシュ・分類は保持します。そのため元環境で削除されたスレッドが残る場合があります。
- 起動・手動更新・フォーカス復帰・前景の定期更新で同期。失敗時は最大8分まで間隔を広げます。フックの導入や既存設定変更はありません。
- タイトル・作業場所はローカル DB に平文保存されます。OS のユーザーアカウントとディスク暗号化で保護してください。認証情報はコピーしません。
- チャット閲覧は `thread/items/list` のみ使用し、明示的な送信で初めて `thread/resume` / `turn/start` を呼びます。送受信内容は Codex 自身の履歴に保存されます。treadcraft の DB・ログには本文を保存しません。本文はプレーンテキスト（改行保持）で、HTML・画像URLを実行・取得しません。
- チャットの「実行権限」で読み取り専用（初期値）、ワークスペースへの書き込み、フルアクセスを選択できます。実行権限の選択は次の送信から適用され、全チャット共通のデフォルトとして端末に保存します。新規・既存チャットとアプリ再起動後にも反映し、実行中のリクエストには影響しません。ワークスペースへの書き込みは作業フォルダと一時フォルダが対象で、ネットワークは制限されます。フルアクセスはフォルダ外の操作とネットワーク接続も許可します。送信時は `on-request` approval・`user` reviewer を指定し、ターンにローカル実行環境とスレッドの作業フォルダを指定します。承認・追加入力の要求は許可せず、そのターンを停止します。添付、ツール承認UI、Markdown装飾は未対応です。Codex の既存設定（MCP・フック等）は読み込まれます。ファイル sandbox は外部連携全般の無作用を保証するものではありません。
- アプリ内では異なるチャットを同時に実行でき、停止は対象チャットのみに適用します。全体10分のタイムアウトと終了時キャンセルがあり、このアプリが起動した App Server のみ回収します。

DB は Tauri のアプリデータディレクトリ内の `local.treadcraft.desktop/board.sqlite` 相当（OS によりパスが異なります）。macOS は `~/Library/Application Support/local.treadcraft.desktop/board.sqlite`。バックアップする場合はアプリを終了してから保存してください。

## 検証

```sh
npm test
npm run build
npm run format:check
cargo test --manifest-path src-tauri/Cargo.toml --locked
cargo fmt --manifest-path src-tauri/Cargo.toml --check
cargo clippy --manifest-path src-tauri/Cargo.toml --all-targets --all-features --locked -- -D warnings
npm run tauri -- build --debug --no-bundle
```

任意の実データ接続チェック（会話・分類を変更せず、件数と一致可否のみ出力）:

```sh
npm run probe:codex
cargo run --manifest-path src-tauri/Cargo.toml --example probe --locked
```

## 実装状況

画面・分類永続化・Codex 一覧取得・失敗表示まで実装。署名・公証・配布、他 OS 実機 QA、会話を元アプリで開く操作、複数選択は未実装。設定画面は接続方法の案内であり、CLI パスの GUI 編集はありません。

詳しい検証証跡と残課題は [実装記録](docs/implementation.md)、初期案は [設計書](docs/design.md) を参照してください。

新しいチャットの「ワークスペースを検索」で、既存の会話に使われたフォルダを名前・パスの部分一致（大文字小文字を区別しない）で絞り込めます。候補がない場合は「別のフォルダを指定…」から絶対パスを入力できます。

ヘッダーの未読チップ一覧は、アーカイブを除く全グループの未読スレッドを更新順で表示します。チップをクリックするとチャットを開き、既読の保存が成功すると一覧から消えます。候補が多い場合は横スクロールできます。

各スレッドカードの「☆」でお気に入りに登録でき、「★」で解除できます。登録すると「最近の会話」の下にお気に入りが登録順のバッジで表示され、クリックすると対象のチャットを開きます。未読のスレッドには未読マークも表示します。お気に入りは端末のローカルストレージに保存され、アプリ再起動後も保持します。アーカイブ済みのスレッドはお気に入り一覧には表示せず、登録情報は保持します。解除しても会話は削除されません。
